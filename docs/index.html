Slab & Signal

A self-updating tracker for collectible Pokémon TCG singles. Prices refresh daily from TCGplayer market data via the free TCGdex API, and the whole thing runs for $0/month on GitHub Actions + Pages.

How it works

  • Screen — every secret rare in every modern set is priced daily; chase-art cards between $5 and $50 make the cut, ranked by model upside.
  • Model — each set moves through hype-fade → supply-trough → recovery → appreciation; rarity tier and character popularity adjust the curve.
  • Momentum — read from Cardmarket's smoothed trend against its 30-day average, shrunk toward zero when a card's sales are too thin to trust.
  • Confidence — the listing spread and any US/EU price disagreement set how wide the projected range is, instead of a flat guess on every card.
  • Scoring — every prediction is logged and graded at 30/90/180 days against a "price stays flat" baseline, so the model has to prove it beats doing nothing.
  • Signal — Discord pings fire only when a card flips to BUY or SELL, so alerts stay actionable.

Fine print

Model output is a structured guess, not financial advice — always check recent sold listings before spending real money. Momentum stats fill in as the tracker builds its own price history day by day.

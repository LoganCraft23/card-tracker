The theory

A set moves through predictable phases — hype-fade, supply trough, recovery, appreciation. Rarity tier and character popularity bend the curve. Foil Theory prices that idea daily and keeps score.

Method

  • Screen — every secret rare priced daily; chase art between $5 and $50 makes the cut.
  • Momentum — Cardmarket's smoothed trend against its 30-day average, shrunk toward zero when sales are too thin to trust.
  • Confidence — listing spread and US/EU disagreement set how wide each range is.
  • Scorecard — predictions graded at 30/90/180 days against "price stays flat".

Fine print

Model output is a structured guess, not financial advice — check recent sold listings before spending real money. Prices via the free TCGdex API.
